最初のファイルを用意する

自分が使うツールに合わせて、名前と置く場所を決めます。

ここから、自分のプロジェクトで準備します。今回は「ファイルを用意する」まで進めます。何を書くかは、次のページで一緒に整理します。

このページの到達点プロジェクトの一番上のフォルダに、使うツールに合ったファイルがある状態にします。

まず、プロジェクトのフォルダを開く

これから開発するプロジェクトを、普段使うエディタで開きます。そのプロジェクト全体をまとめる、一番上のフォルダを確認してください。これを「プロジェクト直下」または「ルート」と呼びます。

すでにAGENTS.mdやCLAUDE.mdがあれば、開いて内容を確認します。チームが用意したファイルを、空のファイルで置き換えないでください。

使うツールの手順を選ぶ

Codexを使う場合

  1. エディタで、プロジェクト直下に新しいファイルを作ります。
  2. 名前をAGENTS.mdにします。
  3. 保存します。

Claude Codeを使う場合

  1. エディタで、プロジェクト直下に新しいファイルを作ります。
  2. 名前をCLAUDE.mdにします。
  3. 保存します。

使っているツールの手順だけを進めれば大丈夫です。両方を使う場合も、まず一方のファイルで基本を学び、共有方法は後から確認できます。

ファイル名を確認する

大文字・小文字を含め、上に示した名前で保存します。Windowsでは、末尾に.txtが付いていないか、エディタのファイル一覧で確認してください。

AIに初期案を作ってもらう方法もある

手動で作るほかに、AIにプロジェクトを調べてもらい、内容の初期案を作る方法があります。/initは、そのためのコマンドです。この手順は手動作成の代わりに使えます。

以下は端末で使うCodex CLI / Claude Codeの手順です。端末は、文字でコマンドを入力する画面、CLIはその画面で操作する形式のことです。両ツールが利用できる状態を前提としています。

/initで初期案を作る手順を見る
  1. エディタで対象プロジェクトを開き、統合端末（エディタ内で使える端末）を開きます。端末の現在の場所を、WindowsのPowerShellではGet-Location、Macではpwdで確認します。対象プロジェクトの一番上のフォルダでなければ、cd "プロジェクトの絶対パス"で移動します。「プロジェクトの絶対パス」は実際の保存場所に置き換えます。
  2. Codexはcodex、Claude Codeはclaudeを実行して起動します。
  3. 起動したAIの入力欄に、下のコマンドを入力します。
AIの入力欄に入力するコマンド
/init

CodexはAGENTS.md、Claude CodeはCLAUDE.mdの初期案を作ります。エディタで生成されたファイルを開き、書かれた方針やコマンドがプロジェクトと合うか確認します。

空のプロジェクトでは、調べられる情報が少ないことがあります。手書きで短く始め、構成が決まってからAIに見直してもらう方法でも十分です。

ここまでの確認

エディタのファイル一覧にAGENTS.mdまたはCLAUDE.mdがあり、開ければ、このページの準備は完了です。手動で作った場合、まだ空でも問題ありません。次のページで内容を書いてから使います。
