# AI開発の指示とスキル
AGENTS.md / CLAUDE.mdを知らない開発メンバー向けの、日本語の学習サイトです。「知る → 流れを見る → 用意する → 書く → 使う → 見直す」の基本6ページから、指示の適用範囲、整理と運用、Skillの理解と作成へと学びます。開発中に必要なページを見返すこともできます。

## 閲覧

`index.html`をブラウザで開いてください。ローカルファイルでも教材を読めます。コピーAPIを利用できない場合は本文を選択し、手動でコピーする案内が表示されます。

Pythonが利用できる場合は、プロジェクト直下で次のコマンドを実行すると、ローカルのHTTPプレビューを使えます。

```sh
python -m http.server 4173 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:4173/` を開きます。依存パッケージのインストールやビルドは不要です。

## 構成

- `index.html`：基本・適用範囲・整理と運用・Skillの教材一覧、タイトル・概要・関連語の検索
- `01_what_is.html`〜`06_maintain.html`：基本を順番に学ぶ6ページ
- `07_personal_project.html`〜`08_folders.html`：個人・プロジェクト・フォルダごとの適用範囲
- `09_organize.html`〜`12_troubleshooting.html`：分割・併用・関連する仕組み・トラブル対応
- `13_what_is_skill.html`〜`15_meeting_skill.html`：Skillの役割・構成・会議運営Skillの作成実習
- `assets/css/styles.css`：全ページ共通のスタイル
- `assets/js/script.js`：検索、コード表示、コピー操作
- `assets/img/`：使う流れ・更新・Skill利用のPNG補助図とファビコン
- `DESIGN.md`：共通デザインと教材の表現方針

技術情報の確認日は各ページに記載しています。更新時は公式資料と利用環境を確認し、仕様と運用上の提案を区別してください。
